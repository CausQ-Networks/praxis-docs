## Feature Requests

We encourage you to submit feature requests in the [GitHub Discussions section](https://github.com/CausQ-Networks/praxis/discussions) of the Praxis repository. This allows the community to:

- **Upvote features** they want to see implemented
- **Provide feedback** and suggestions on proposed features
- **Discuss implementation details** and alternatives
- **Help prioritize** which features to work on next

<Note>
Feature requests with community support (upvotes and positive feedback) are more likely to be prioritized for development.
</Note>

## Bug Reports

Bug reports should be submitted in GitHub Issues for the relevant repository:

### Server Components

- **Praxis**: [causq-networks/praxis/issues](https://github.com/CausQ-Networks/praxis/issues)
- **Newt**: [causq-networks/praxis-newt/issues](https://github.com/CausQ-Networks/praxis-newt/issues)
- **Gerbil**: [causq-networks/praxis-gerbil/issues](https://github.com/CausQ-Networks/praxis-gerbil/issues)

### User Clients

- **Windows App**: [causq-networks/windows-linux/issues](https://github.com/CausQ-Networks/praxis-desktop/issues)
- **Linux App**: [causq-networks/windows-linux/issues](https://github.com/CausQ-Networks/praxis-desktop/issues)
- **Android App**: [causq-networks/android/issues](https://github.com/CausQ-Networks/praxis-android/issues)
- **Apple Apps**: [causq-networks/apple/issues](https://github.com/CausQ-Networks/praxis-apple/issues)
- **Praxis CLI**: [causq-networks/praxis-cli/issues](https://github.com/CausQ-Networks/praxis-cli/issues)
- **Olm**: [causq-networks/praxis-olm/issues](https://github.com/CausQ-Networks/praxis-olm/issues)

Using the correct repo ensures:

- **Proper tracking** of bugs through their lifecycle
- **Developer visibility** for quick resolution
- **Version tracking** and regression testing
- **Duplicate detection** and consolidation

<Warning>
Please provide as much detail as possible to help developers reproduce and fix the issue quickly.
</Warning>

## Before Submitting

- Search existing discussions and issues to avoid duplicates
- Provide clear, detailed information
- Include steps to reproduce (for bugs)
- Test on the latest version of Praxis
- Check if the issue is environment-specific
