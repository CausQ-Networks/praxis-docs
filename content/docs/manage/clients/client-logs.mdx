---
title: "Client Logs"
description: "View Praxis client logs on Windows, Mac, Linux, Android, and iOS"
---
The Praxis apps for Windows, Mac, Linux, iOS/iPadOS, and Android show their logs under **About** > **Logs**, with messages from both the app and the tunnel, and can save them to a file to attach to a support request. The sections below also cover each platform's log files and system tools, and the [Praxis CLI](#cli).

## Windows

Open **Settings** > **About** > **Logs**. Select **Save...** to save them to a file.

You can also open the log file directly. The default location is:

```
C:\ProgramData\praxis\logs\praxis.log
```

To tail the log in PowerShell:

```powershell
Get-Content "C:\ProgramData\praxis\logs\praxis.log" -Tail 0 -Wait
```

## Mac

Open **Settings** > **About** > **Logs**. Select **Save…** to save them to a file.

Praxis also writes to the Apple system logger. To stream its logs in Terminal:

```bash
log stream --predicate 'subsystem == "com.causq.praxis" OR subsystem == "com.causq.praxis.PacketTunnel"' --level debug --style compact
```

## Linux

Open **Settings** > **About** > **Logs**. Select **Save...** to save them to a file.

The log files are at:

- Background service and tunnel: `/var/log/praxis-client/`, also available with `journalctl -u praxis-client` on systemd
- App: `~/.local/state/praxis-client/logs/` (or `$XDG_STATE_HOME/praxis-client/logs/`)

See [Linux](/manage/clients/platforms/linux#background-service).

## CLI

The default log file location is:

```
~/.config/praxis/logs/client.log
```

If you run `praxis up` in detached mode, you can tail logs with:

```bash
praxis logs client -f -n 10
```

This example follows new log lines and shows the last 10 rows.

Alternatively, run in attached mode to see logs in the current terminal session:

```bash
sudo praxis up --attach
```

## Android

Open **About** > **Logs**. Praxis saves tunnel logs automatically once you connect. Select **Download Logs** to save them to a file. See [Android](/manage/clients/platforms/android).

## iOS/iPadOS

Open the **About** tab, then **Logs**. Tap the share button to save or send them, or use **More** to copy them.

For more detail, attach the iPhone or iPad to a Mac and use Console.app. Add a **Subsystem** filter for:

```
com.causq.praxis
```
