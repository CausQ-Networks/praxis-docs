---
The update process depends on how you originally installed the site.

Find the latest version in the [GitHub releases](https://github.com/CausQ-Networks/praxis-cli/releases).

<Note>
If you installed Newt instead of the Praxis CLI, see [Install Newt](/manage/sites/install-newt) for Newt-specific commands.
</Note>

## Docker Installation

Update the image version in your `docker-compose.yml`:

```yaml title="docker-compose.yml"
services:
  praxis-site:
    image: causq-networks/praxis-cli:{version} #  Replace {version} with the latest version tag
    # ... rest of config
```

Then pull and restart:

```bash
docker compose pull praxis-site
docker compose up -d praxis-site
```

## Binary Installation

### Auto Installer (Recommended)

If you used the auto installer, simply run it again.

```bash
curl -fsSL https://praxis.causq.com/get-cli.sh | bash
```

### Manual Installation

Download the latest binary for your system from [GitHub releases](https://github.com/CausQ-Networks/praxis-cli/releases) and replace your existing binary.
